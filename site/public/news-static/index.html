관계 지도

사건 구조에서는 기사 제목에 명시된 인수자·인수 대상·매도자를 연결합니다. 역할이 확인되지 않으면 직접 언급 기업만 표시합니다. 연관 이슈에서는 같은 기업이 등장하는 다른 이슈를 선택 기간 내 전체 목록으로 보여줍니다. 중요도 점수가 높은 순서이며 동점은 최신순입니다. 미평가 뉴스의 점수는 임시 선별 기준입니다. 공통 기업 버튼으로 연결 근거를 확인할 수 있으며 인과관계를 뜻하지 않습니다. 각 연결은 근거 기사로 확인할 수 있습니다. 단순 키워드는 별도 참고 영역에 표시합니다.

이슈와 중요도

제목 규칙의 점수는 우선 검토 후보를 고르는 기준입니다. Qwen 1차, Luna 2차 검토와 최종 중요도 평가는 서로 다른 단계이며, 검토 후보가 곧 중요한 뉴스라는 뜻은 아닙니다. 최종 평가와 분석 범위는 이슈 상세에서 확인하세요.

유사 보도 묶음과 상태

중요 뉴스 중 같은 기업·사건 분류의 유사한 제목을 24시간 범위 안에서 묶습니다. 같은 사건이라는 보장은 없으므로 모든 원문을 시간순으로 확인할 수 있습니다. ‘미확정 보도’는 제목의 협상·추측 표현에 따른 분류입니다. 해당 표현이 없다고 확정으로 판단하지 않습니다. 최초 보도는 저장된 기사 중 가장 이른 게시 시각입니다.

기사 감성

FinBERT가 제목과 제공된 요약을 긍정·중립·부정으로 분류합니다. 여러 기업이 등장해도 기사 전체의 논조를 공유합니다. 전체 기사 비율과 중요도를 구분해서 읽으세요. 모델 확률은 정확도 보장이 아닙니다.

데이터 범위

Yahoo RSS와 BLS·연준 피드를 사용합니다. 뉴스 전체 본문이나 모든 매체를 수집하는 것은 아닙니다. 누락·게시 지연이 있을 수 있습니다. 주가, EPS 추정치, 수익률 상관관계는 계산하지 않습니다. 새로고침은 저장 데이터를 읽으며 외부 수집이나 모델 호출을 실행하지 않습니다.
